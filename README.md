# Игра в пьяницу

Программа моделирует игру в "пьяницу" для двух игроков.

В игре используются карты с числами от `0` до `9`. Большая карта побеждает
меньшую, но карта `0` побеждает карту `9`.

## Компиляция

Выполнить из папки проекта:

```bash
g++ -std=c++17 src/main.cpp src/domain/CardQueue.cpp src/application/DealValidator.cpp src/application/GameService.cpp src/infrastructure/DealFileReader.cpp src/presentation/ConsoleMenu.cpp -I src -o drunkard_game
```

## Запуск

```bash
./drunkard_game
```

После запуска появится меню:

```text
1. Ввести карты вручную
2. Загрузить карты из файла
3. Показать правила
0. Выход
```

## Пример Ручного Ввода

Выберите пункт `1`.

Введите карты первого игрока:

```text
1 3 5 7 9
```

Введите карты второго игрока:

```text
2 4 6 8 0
```

Результат:

```text
Победил: second 5
```

## Загрузка Из Файла

Выберите пункт `2` и введите имя файла:

```text
example.txt
```

Файл должен содержать две строки:

```text
1 3 5 7 9
2 4 6 8 0
```

Первая строка - карты первого игрока, вторая строка - карты второго игрока.

## Структура Проекта

```text
src/domain          основные структуры и очередь карт
src/application     логика игры и проверка данных
src/infrastructure  чтение из файла
src/presentation    консольное меню
```

Очередь карт реализована вручную на связном списке, без `std::queue`.
